# predictions

Registro inmutable de cada predicción emitida: fecha, acción, señal, probabilidades, retorno esperado, y el resultado real una vez se cumple el horizonte de 20 ruedas.

Una vez escrito un registro aquí, no se modifica — es la base de la trazabilidad exigida en los criterios de aprobación del modelo (`references/marco-metodologico.md`).
