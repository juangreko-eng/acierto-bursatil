# src/reportes

Genera los tres productos semanales a partir de las salidas de los modelos:

1. Ranking de oportunidades (fórmula compuesta, ver `references/reglas-portafolio.md`).
2. Señal individual por acción.
3. Portafolio sugerido (aplicando las reglas de `references/reglas-portafolio.md`).

Salida a `reports/`, en formato legible (Markdown o similar) más un registro estructurado en `predictions/`.
